# Whole-System Predictive Abstraction Contract

This program does not promote a recurring label into a principle. It promotes
only a predictive relationship that survives transformations it did not use to
select itself.

## Observation Identity

The atomic observational unit is:

`platform + format + video_id + outcome_snapshot + representation_contract`

The same YouTube video appearing in the Library, Raw, Saved Channels,
Retention, Promise Lab, or an experiment cache is one observation with multiple
views. It is never counted as independent evidence twice.

Generated hooks, generated thumbnails, model projections, synthetic swaps, and
counterfactual deletions are interventions or diagnostics. They are not
independent YouTube outcomes.

## Evidence Classes

1. `observed_outcome`: public views or private YouTube analytics.
2. `observed_input`: media, title, transcript, timing, or thumbnail captured
   before the target outcome.
3. `representation`: an embedding, projection, component lattice, or cluster
   computed without the target outcome.
4. `projected_target`: a score produced by another learned model. This may rank
   model agreement but cannot validate the real target.
5. `post_outcome_indicator`: retention, shares, likes, subscriber mix, or later
   views measured after publication. These can explain realized performance but
   are not pre-upload predictors.
6. `generated_candidate`: a model-generated idea, hook, title, or image.
7. `manual_probe`: a human-supplied example or vocabulary used to inspect a
   discovered representation. It can name a cluster but cannot validate it.

## Discovery Order

1. Freeze observation IDs, source IDs, timestamps, and representation versions.
2. Discover geometry without outcomes.
3. Measure stability across seeds, algorithms, and resolutions.
4. Attach outcomes only inside training folds.
5. Evaluate on creator-grouped, chronological, and format-held-out folds.
6. Correct the complete candidate family for selection.
7. Seal a future lockbox before collecting its outcomes.

Any outcome used to choose a representation, boundary, cluster count, lag,
feature subset, or label is unavailable to validate that choice.

## Transformation Families

- `seed`: initialization and sampling changes.
- `algorithm`: clustering or estimator family changes.
- `resolution`: component and cluster-count changes.
- `modality`: visual, text, and together inputs.
- `account`: independently held-out creator/account.
- `source`: independently held-out public channel.
- `time`: past-to-future evaluation.
- `format`: Shorts-to-long-form or long-form-to-Shorts transfer.
- `measurement`: raw views, age-adjusted views, outlier, CTR, keep, retention.
- `prospective`: outcomes collected after a sealed prediction.

## Promotion Levels

- `mechanism`: distinguishable and persistent inside one bounded setting.
- `local_invariant`: survives resampling, algorithm, and resolution changes in
  one corpus.
- `regional_invariant`: predicts in unseen accounts or sources in one format.
- `domain_invariant`: survives source and format transfer.
- `universal_invariant`: survives independent domains and prospective tests.

The current data cannot justify a universal invariant.

## Scoring

Candidate promotion is conjunctive, not an average that lets a large sample
hide a failed lockbox:

`level = minimum(discovery, stability, source transfer, time transfer, format transfer, prospective)`

Description length is reported only when the complete executable model and its
encoding are available. Word count is never presented as MDL.

## Views Decomposition

Views are treated as a realized system outcome, not a pure content label:

`realized views = source opportunity x packaging conversion x attention survival x distribution amplification`

The factors may interact. The decomposition is a causal research contract, not
an assumption that the current data has already identified every factor.

## Required Falsifications

- Compare every global result with creator/source-centered performance.
- Compare random-fold results with past-to-future results.
- Compare apparent calibration with cross-video discrimination.
- Test modality agreement instead of counting modalities as independent votes.
- Preserve failed transfer, negative R-squared, leakage, stale maps, and missing
  model versions as first-class results.
- Never infer first-pass retention or replay counts from an aggregate retention
  curve without an identified measurement model.
